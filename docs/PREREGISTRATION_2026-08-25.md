## 5. 진입·청산 방정식
기대 캐리 `μ` = 최근 30일 일별펀딩의 10% 절사평균 × 365 (유효관측 ≥90% 필요, 아니면 NaN)

```
forward 초과 = μ − r_cash
reverse 초과 = −μ − r_borrow(PIT) − r_cash
진입: 초과 ≥ 2 × (2 × leg_cost) × 365 / 30       ( = 9.73%/yr at 40bp 왕복 )
청산: 초과 < −(2 × leg_cost) × 365 / 30           ( = −4.87%/yr )
최소보유: 30일 (적격성 상실·데이터 결측은 예외로 즉시 청산)
```
`leg_cost = spot_fee + perp_fee + 2 × slippage = 0.0010 + 0.0006 + 0.0004 = 0.0020`

**reverse는 계정 고유 PIT 차입금리가 기록된 기간에만 활성화한다.** 오늘의 공개 금리를
과거에 소급 적용하는 것은 금지한다(차입난은 음수 펀딩과 동시 발생 → 편향 방향이 나쁘다).

## 6. 자본구조 (고정)
```
현물명목 / 자기자본  운용목표 0.55, 하드한도 0.65
스테이블 담보        ≥ 현물명목의 50%
총명목 / 자기자본    ≤ 1.30
무거래 밴드          목표 대비 20%
```
스트레스 솔버가 허용하는 89~96%는 **청산 경계이지 운용점이 아니다.** 상향 금지.

감축은 **페어 디레버리지**(현물 매도 + 동일 수량 perp 커버)로만 수행한다.
동일 크기 재진입은 담보여력을 바꾸지 않으므로 완화책이 아니다.
