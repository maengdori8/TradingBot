## 0. 왜 v1을 폐기했는가
v1은 구현과 불일치했다: reverse 캐리를 서술했으나 코드는 금지하고, 목표 0.55·밴드 0.20을
적었으나 코드는 0.50·0.10이며, 담보 규칙과 부트스트랩 반복수도 달랐다. 사전등록 문서가
코드와 다르면 사전등록이 아니다.

## 1. 확증적 지위 (중요)
2026-08-25 이전의 **모든** 결과는 탐색적이다. 다음을 전부 관찰한 뒤 설계를 확정했기 때문이다:
6개 전략군 기각, 설정 격자 18+9개, 지속성 horizon 6개, 2025 과회전, 2026 가뭄, 비용 스트레스
5수준, 현금금리 3수준, USDT-USDC perp 차이, 만기선물 베이시스, VRP, 역방향 캐리,
생존편향 교정 유무. **확증은 2026-08-26 이후 데이터로만 가능하다.**

## 2. 전략 (코드와 1:1 대응)
```
유니버스   = 전일 ADV(양다리 중 얇은 쪽, 30일 중앙) 상위 2
적격       = 현물·perp 동시 상장 AND perp 상장 후 ≥180일
             AND 전일 ADV ≥ $20M AND 알려진 폐지일까지 ≥30일
             AND 당일 현물·perp 가격과 펀딩이 모두 관측됨
신호 μ     = 최근 30일 일별펀딩의 10% 절사평균 × 365 (유효관측 ≥90%, shift(1))
진입       = μ − r_cash ≥ 2 × (2 × leg_cost) × 365/30      ( = 9.73%/yr )
청산       = μ − r_cash < −(2 × leg_cost) × 365/30          ( = −4.87%/yr )
최소보유   = 30일 (적격성 상실·데이터 결측은 즉시 청산, 잠금보다 우선)
방향       = forward(현물 롱 + perp 숏) 전용. reverse는 코드가 거부한다.
```
`leg_cost = 0.0010(현물) + 0.0006(perp) + 2 × 0.0002(슬리피지) = 0.0020`

## 3. 자본구조
```
현물명목 목표      자기자본의 50%
증액 정지선        60%
하드 한도          65%   (불변식, 위반 시 REDUCE)
거래소 스테이블    현물명목의 70%   ( S/(S+C) = 0.588 < 0.65 를 만족 )
무거래 밴드        목표 대비 10%   ( 0.50 × 1.10 = 0.55 < 0.60 )
담보 이체          목표 대비 20% 이탈 시에만, 편도 5bp 부과
포지션 상한        전일 ADV의 1%
```
`__post_init__`이 이 관계를 강제한다. 스트레스 솔버가 허용하는 89~96%는 청산 경계이지
운용점이 아니다. 상향 금지.

## 5. 회계
- 현금은 `cash_exchange`(증거금 인정)와 `cash_offvenue`(현금수익 획득)로 분리한다.
- 자기자본 = 현금 + Σ(방향×수량×현물가) + Σ(방향×수량×(perp진입가 − 마크))
- 부과 비용: 수수료, 슬리피지, 강제청산(가격 결측 시 2배), 디레버리지, 담보 이체, 종료 청산
- 무결성 불변식: `∏(1 + 일별수익) == 최종자기자본 / 평가시작자기자본` (테스트로 강제)

## 6. 1차 성과지표
**실현 가능한 현금 대비 자기자본 복리 초과수익률.**
- 부트스트랩: 정상 블록, 기대 블록 180일, 3,000회, seed 11 (코드 기본값과 일치)
- 보조: 에피소드 단위 부트스트랩 (평→평, 경계행 포함, 현금 대비 초과)

## 7. 승급 요건 (둘 다 충족해야 평가 개시)
- **활성화 에피소드 ≥ 12회**
- **경과 ≥ 24개월**
과거 5년에서 관측된 에피소드는 **4회**뿐이다. 통계적 검정력이 사실상 없다는 뜻이며,
이것이 전향적 축적을 요구하는 이유다.

## 8. 기각 조건
1. 초과수익 CAGR 부트스트랩 하한 ≤ 0
2. 단일 종목이 총 초과 P&L의 50% 초과
3. 자기자본 낙폭 > 5%
4. 섀도우 증거금과 Bybit 권위값 괴리 > 20%
5. EMERGENCY 2회 이상
6. 실현 슬리피지가 가정(2bp)의 3배 초과

## 9. 자본 상한
이 계좌는 총 투자가능자산의 **2.5% 이내**. 활성화 시 자기자본의 **최대 93%가 Bybit에 놓인다.**
MDD 0.19%는 거래소 파산·출금정지·폐지 갭을 **포함하지 않는다** — 이 트레이드를 지배하는 위험은
바로 그것들이며 손절로 막을 수 없다.

## 10. 알려진 미해결 사항 (승급 전 필수)
1. 폐지 종목의 **PIT 일별 ADV·가격**이 없다. 현재 합성 시나리오(베이시스 0, 상수 ADV)는
   증거가 아니며 보고에서 분리 표기한다.
2. 폐지 **공지 시각**이 아니라 확정 폐지일을 쓴다 → 30일 버퍼는 룩어헤드 소지가 있다.
3. 펀딩 명목에 정산시점 마크가 아니라 일 종가를 쓴다.
4. 계정 고유(인증) 차입금리·MMR·담보가치가 기록되지 않는다 (공개 No VIP 값만).
5. 담보 이체의 **지연**을 모델링하지 않는다 (비용만 부과).
6. reverse 캐리는 부채 인지형 리스크 모델이 없어 비활성이다.
