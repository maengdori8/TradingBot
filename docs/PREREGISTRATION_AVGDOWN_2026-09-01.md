## 0. TL;DR

**추매(물타기) 사다리 구조 공간 1,248 시행(전수 1,536 에서 중복 제거)을 실행 전에
전수 확정한다.** 롱 온리, BTC/ETH/SOL USDT 무기한, 15m/1h. 1차 지표는 **3심볼 균등
합산 일별 순수익률 평균**(연환산 Sharpe 병기), 귀무는 **순수익 ≤ 0**. 보정은
White's Reality Check — **스케일 ω̂ 는 원표본에서 1회 추정해 고정**(경로별 재추정
금지 — SWEEP-2026-08-31 §13 오지정 사고의 구조적 재발 방지), 정상(stationary)
부트스트랩 평균 블록 5일, 1,000 경로, seed **20260901** — 에 Romano–Wolf StepM
(α=0.05)·DSR(≥0.95) 병기. 통과 기준: **RC p < 0.05 AND StepM 기각 ≥ 1 AND DSR ≥ 0.95**.

**이 저장소의 데이터는 이미 여러 연구에 재사용된 표본이다. 생존자가 나와도 즉시
승급은 불가하며 전향(신규 기간) 검증이 필수다** — 이 문장은 결과와 무관하게 유효하다.

## 1. 지위

- **탐색 1회성 (one-shot).** 본 문서에 열거되지 않은 진입·간격·배수·심볼·타임프레임·
  비용·기간은 이 트랙에서 영원히 검정될 수 없다.
- **자본 권한 없음.** 최선의 결과도 "전방 페이퍼 후보 자격"까지다. 생존자는 별도
  사전등록의 전향 검증(백테스트가 아닌 신규 기간)을 통과해야 한다.
- **가설 생성 장치이지 검증 장치가 아니다.** 동결 과거 데이터 백테스트는 아무리
  보정해도 전방 증거가 아니다 (§2.2 데이터 재사용).
- 판정은 §6 의 사전 지정 절차 1회뿐이다. 재실행·재해석·추가 검정은 §8 이 금지한다.

### 2.2 데이터 재사용 (핵심 한계)

편향이며 동결 데이터 안에서 교정 불가. 결과 해석 시 반복 공시한다.

### 2.4 SWEEP-2026-08-31 §13 오지정 사고 (본 문서가 상속하는 교훈)
동결 문언이 RC 분모(스케일)를 **경로마다 재추정**하도록 규정했고, 그 구성은
희소거래 규칙이 귀무분포를 지배해 임계값이 연환산 +31 로 폭발했다(검정력 사실상 0).
White(2000)·Hansen(2005) 원형은 **스케일을 원표본에서 한 번만 추정해 고정**한다.
본 문서는 처음부터 고정 ω̂ 구성을 동결하며(§6.2), `lab/avgdown_verdict.py` 의
selftest 가 "경로별 재추정 구성과 결과가 다르다"를 강제해 오지정을 탐지한다.

## 3. 규칙 공간 (전수 열거 — 동결)

### 3.0 공통 정의
| 기호 | 정의 |
|---|---|
| 확정봉 | 신호 계산에 쓰는 마지막 완결 봉 `[i−1]`. 형성중 봉 절대 미사용 |
| 체결봉 | `[i]` — 주문이 나가는 봉. 비돌파형 체결 = `open[i]` |
| `ATR24` | `lab/bbadd_test.py` `atr()` 동형: TR = **previous close 기준** `max(h−l, \|h−pc\|, \|l−pc\|)` (skipna, 첫 봉 = h−l), Wilder `ewm(alpha=1/24, adjust=False)`. 신호·레벨은 항상 `ATR24[i−1]` |
| `BB(20,2)` | 중심 `SMA20`, 밴드 `± 2 × std20(ddof=0)` (모표준편차 — 출판 관례, bbadd 동형) |
| `RSI14` | Wilder `ewm(alpha=1/14)`. `dn==0 → 100`, 무변동 → 50 — `lab/sweep_engine.py` `Feat.rsi` 규약의 수치 동일 복사(셀프테스트가 동일성 강제) |
| `SMA200` | 확정봉 종가 단순이동평균, 봉 개수 기준(타임프레임 재스케일 없음 — 15m 의 SMA200 = 50시간, 1h = 200시간. Track E §11 이식 관례와 그 한계 승계) |
| 방향 | **롱 온리** (전 시행) |

### 3.1 진입 (2)
- **E1**: 확정봉 종가 < BB(20,2) 하단밴드.
- **E2**: 확정봉 RSI(14) < 30.
- 체결 = 다음 봉 시가. 보유 중 신규 진입 신호 무시(추매 경로만). 청산 봉 재진입 금지.
- fail-closed: 확정봉 종가·해당 지표가 NaN 이면 무행동 (E2 도 확정봉 종가 유한성 요구).

### 3.2 추세 필터 (2)
- **F0**: 없음. **F1**: 확정봉 종가 > SMA200[확정]. SMA200 미형성(NaN) = 진입 차단
  (fail-closed). 필터는 **신규 진입에만** 적용된다 — 추매·청산은 필터와 무관
  (bbadd_v2_check 설정 C 동형).

### 3.3 추매 사다리 (간격 4 × 최대추매 4)
- 간격 `g ∈ {0.5, 1.0, 1.5, 2.0}` ×ATR24, 최대추매 `k_max ∈ {0, 1, 2, 3}`
  (트랜치 하드캡 = `k_max + 1`).
- **트리거 = 직전 트랜치 체결가 − g × ATR24[그 체결봉−1]** — 트랜치 체결 시 **동결**,
  다음 트랜치 체결 시 재동결(**재귀**). 확정봉 종가 ≤ 트리거 → 다음 봉 시가 추매.
- 체결봉의 ATR 이 NaN/비양수면 트리거 = NaN → 추매 불능 (fail-closed, bbadd 동형).
- 일손실 정지(§4.4) 중에는 추매도 차단된다.

### 3.4 익절 (4)
- **T-MID**: 확정봉 종가 ≥ SMA20[확정](BB 중심선) → 다음 봉 시가 전량 청산 (bbadd 동형).
- **T-A0.5 / T-A1.0 / T-A2.0**: 레벨 = **평단 + {0.5, 1.0, 2.0} × ATR24[마지막
  체결봉−1]** — 트랜치 체결·추매 시 재동결(손절과 동일 규약, ATR 불량 시 기존 레벨
  유지). **확정봉 종가 ≥ 레벨 → 다음 봉 시가 전량 청산.**
- **결정론 확정 D1**: ATR 익절도 **종가 확인형**(봉내 리밋 아님)으로 확정한다.
  과제 문언은 T-MID 만 "종가"를 명시했으나, 봉내 리밋 모델은 봉내 경로 미지 하에서
  낙관 체결(고가 터치 = 체결 가정)이 되므로 보수적·통일적 형태를 실행 전에 고정한다.

### 3.5 손절 (3)
- **S0**: 없음. **S6 / S10**: 레벨 = **평단 − {6, 10} × ATR24[마지막 체결봉−1]** —
  체결·추매 시 재동결, ATR 불량 시 기존 레벨 유지 (bbadd_v2_check 설정 B 동형).
- 봉내 스탑주문: `low[i] ≤ 레벨` → 체결 = **min(open[i], 레벨)** (갭 악화 — max 아님).
- 진입·추매가 이뤄진 같은 봉에서도 손절은 검사된다(체결 직후 상태 반영, bbadd_v2 동형).

### 3.6 타임프레임 (2)
**15m / 1h.** 지표 파라미터는 봉 개수 기준으로 불변(재스케일 없음). 15m 시행의
부정 결과는 1h 시스템의 반증이 아니며 그 역도 같다 — 한계 공시.

### 3.7 중복 제거 규약 (동결 — N 산출)
`k_max = 0` 이면 추매가 없어 간격 차원이 시뮬레이션에 **아무 영향도 주지 않는다**
(전수 곱을 그대로 두면 동일한 수익률 열 4벌이 N 을 부풀려 RC·DSR 의 보정을
왜곡한다). 따라서 **`k_max = 0` 은 간격을 무표기(`sp=-`) 대표 1개로만 열거한다**:

```
사다리 조합 = {(-, 0)} ∪ {(g, k) : g ∈ {0.5,1,1.5,2}, k ∈ {1,2,3}}  →  1 + 12 = 13
N = 진입 2 × 필터 2 × 사다리 13 × 익절 4 × 손절 3 × 타임프레임 2 = 1,248
```

(전수 곱 2×2×4×4×4×3×2 = 1,536. 1,536 × 13/16 = 1,248.) 열거는
`lab/avgdown_sweep.py::enumerate_trials()` 가 격자 상수에서 결정론적으로 생성하며
(순서: tf → 진입 → 필터 → 사다리 → 익절 → 손절), 셀프테스트 (c) 가 N 과 ID 유일성을
강제한다. **이 1,248 이 다중검정 보정의 N 이다.**

### 4.2 평가 창 (전 시행 동일 — 동결)
- **일수익률 관측일 `d` = 2021-01-06 … 2026-08-23 UTC → T = 2,056.**
  자정(UTC 일말) 자본 스냅샷 2021-01-05 … 2026-08-23, 총 2,057개에서
  `r_d = eq_d / eq_{d−1} − 1`.
- 시작 근거: 최초 심볼 BTC 의 첫 봉(2021-01-01 00:00) + 워밍업 100봉(1h) →
  첫 주문 가능 시각 2021-01-05 04:00 → 첫 온전한 수익률 일 = 2021-01-06.
- 종료 근거: 펀딩 데이터 종료(2026-08-24 00:00) → 마지막 온전한 일 = 2026-08-23.
  SOL 의 여분 봉(→ 08-26)은 평가 창 밖이다.
- **심볼 슬리브는 자기 데이터 시작 전 = 현금(수익률 0)** 이다. ETH 는 2021-03,
  SOL 은 2021-10 부터 수익률이 발생한다 — 균등 1/3 배분에서 미가동 슬리브는 0% 로
  들어간다 (§4.5). 전 시행이 정확히 같은 2,056 일 그리드를 쓴다.
- **결정론 확정 D5**: 표본 말 미청산 포지션의 강제청산(`eod`, 마지막 유효 종가,
  비용 차감)은 평가 창 **밖**(2026-08-24 이후 스냅샷 없음)에서 일어나므로 1차
  지표에 반영되지 않는다. 창 마지막 날의 자본은 MTM 이다. 전 시행 동일 조건.
- **결정론 확정 D4**: 어떤 날의 시작 자본이 0 이하면 그날 수익률은 0 (산술 정의 —
  무손절 만재 사다리는 자본 소진이 가능하다. 사후 필터가 아니다).

### 4.3 실행 인과성 (위반 시 결과 폐기)
1. 모든 신호 = 확정봉 `[i−1]` 종가·지표(`shift(1)`). 체결 = 봉 `[i]` 시가.
   신호봉 종가 체결 금지. 형성중 봉 절대 미사용.
2. TR = previous close 기준. ATR·레벨은 항상 `ATR24[i−1]`.
3. 봉 `[i]` 의 동일봉 데이터 사용은 (a) 체결가 `open[i]`, (b) 손절 봉내 트리거
   `low[i]`, (c) 봉 마감 후 MTM·일손실 정지 판정 `close[i]` 뿐. `close[i]` 는
   어떤 체결가·신호도 되지 않는다.
4. 추매 트리거·손절·ATR 익절 레벨은 체결 시 **동결**값만 사용 (§3.3~3.5).
5. 같은 봉 우선순위: **익절(시가) > 추매(시가) > 손절(봉내)** — 시가 체결이 봉내
   터치보다 시간상 선행. 익절된 봉의 재진입 금지.
6. 손절 갭: 시가가 레벨 아래면 시가 체결 (악화 — `min(open, 레벨)`).
7. 워밍업 100봉(해당 타임프레임) 무주문 — bbadd_test 동결 관례 승계 (**D2**:
   15m 의 100봉 = 25시간. SMA200·BB 등 장주기 지표는 자체 NaN fail-closed 로
   실질 워밍업이 더 길다. 기준 시행과의 수치 동일성(§9 (a))을 위해 100 을 유지).
8. 결측·NaN·펀딩 결측 = 무행동/무차감 + 그대로 기록 (fail-closed, 보간·추정 금지).
   심볼 데이터 종료 시 마지막 유효 종가 강제청산(`eod`).

### 4.4 자본 모델 (bbadd_test 단독 슬리브 동형 — 동결)
- **슬리브 독립 (D3)**: 심볼별 슬리브가 각자 자본 1.0 으로 시작한다.
  `bbadd_test` 본안(3심볼 공유자본)과 다른 점을 공시한다 — 시행 간 비교가능성과
  심볼별 참고 지표의 순수성을 위해 슬리브를 분리했다. 기준 시행 대조(§9 (a))는
  동결 엔진의 **단독 슬리브 런**(`syms=(s,)`)과 수치 동일성으로 수행한다.
- 트랜치 명목 = **equity × 1/12** (bbadd 동결 — `k_max` 와 무관하게 동일. 만재
  명목은 `(k_max+1)/12`), 체결 시점 equity 기준.
- gross 캡 10x · heat 캡 6% (**D6**: heat 기여 = 명목 × 5% 대리 — 손절 유무와
  무관하게 전 시행 통일. E15/bbadd 동결 정의 승계. 단독 슬리브에서는 사실상
  비구속 — 구조적 성질 공시) · 일손실 −5% **진입·추매 정지** (청산 없음).
- 비용: 테이커 편도 8bp(체결 명목 기준) = 왕복 16bp.
- 펀딩: `funding.parquet` 8h 그리드의 **일합을 일 시작에 선차감** (롱 지불,
  직전 확정 종가 마킹) — bbadd_test·scalp_grid 계승 동일 소스·방식.

### 4.5 시행 단위 (동결)
시행 1개 = {규칙} × {타임프레임} 의 **3심볼 균등 합산 셀**:
`r_d(시행) = (r_d^BTC + r_d^ETH + r_d^SOL) / 3` (미가동 슬리브 = 0). 이것이 1차
지표의 수익률 열이다. 심볼별 열은 참고 전용(§5.3)으로 함께 기록한다.

## 5. 지표 (동결)

### 5.1 1차 지표 — 일별 순수익률 평균
`stat_k = mean(r_d)` (비용·펀딩 차감 후, §4.5 합산 열). 검정 통계량은 이를
고정 스케일로 스튜던트화한 `T_k = √T · mean / ω̂` (§6.2). **연환산 Sharpe
(`mean/std(ddof=1) × √365`)와 연환산 평균수익률(`mean × 365`)을 병기**하되 판정
권한은 §6 게이트에만 있다.
- 퇴화 처리 (동결): 거래 0 / 상수 열 → `T_k := 0`, **N 산입 유지** (사후 제거 금지).
- 최소 거래 수 필터 없음.

### 5.2 보조 지표 (판정 권한 없음 — 보고 전용)
거래 수, 승률, 심볼별 최종자본, MDD, 연도별 분해. 보조 지표로 승격·탈락 불가.

### 5.3 심볼별 참고
심볼별 수익률 행렬에 동일 기계를 적용한 RC·StepM 을 **참고 전용**으로 병기한다.
**심볼별 결과로 시행을 구제·승격할 수 없다** (하위표본 구제 금지 — SWEEP §9.2-12 승계).

## 6. 다중검정 보정 (동결)

### 6.1 귀무가설
> **H0: 1,248 시행 전부에 대해 비용·펀딩 차감 후 일수익률의 기댓값이 0 이하다.**
> (단측 — "순수익 ≤ 0". 대립 = 어느 시행이든 순수익 > 0.)

### 6.2 White's Reality Check — 고정 스케일 (1차 게이트)
1. 1,248 × 2,056 일수익률 행렬 `R` (§4.5).
2. **ω̂_k = std(r_k, ddof=1) 를 원표본에서 1회 추정해 고정한다.**
   관측 통계량 `T_k = √T · mean(r_k) / ω̂_k`.
3. 귀무 부과: 각 열 평균 0 중심화(퇴화 열은 정확히 0). 분산·왜도·시행 간
   교차상관 보존 (least favorable configuration).
4. **동기화 stationary bootstrap** (Politis–Romano): 블록 길이 기하분포 **평균
   5일**(≒ 15m 480봉, 1h 120봉 상당 — 부트스트랩 자체는 **일수익률** 위에서
   수행한다), **1,000 경로**, **seed 20260901**. 한 경로의 날짜 수열을 1,248 시행
   전부에 동일 적용.
5. 경로 `b` 마다 `T*_{b,k} = √T · mean(r*_{b,k}) / ω̂_k` — **분자만 재계산, ω̂ 는
   경로에서 절대 재추정하지 않는다** (§2.4 오지정 사고의 동결 교정. 위반 구성과의
   차이를 `lab/avgdown_verdict.py` selftest 가 강제 검출한다).
6. `p = (1 + #{b : max_k T*_{b,k} ≥ max_k T_k}) / (1,000 + 1)`.
   p 해상도는 1/1001 ≈ 0.001 — 경로 1,000 은 α=0.05 판정에 충분하다 (공시).

평균은 표본 다중집합의 대칭함수이므로 중복도 행렬 항등식(`C @ Rᵀ / T`)을 쓴다 —
SWEEP-2026-08-31 §6.2 규약 계승, `lab/sweep_verdict.py` 의 동결 기계를 읽기 전용
임포트한다.

### 6.3 Romano–Wolf StepM (생존 집합 — α=0.05)
동일 부트스트랩(동일 seed·인덱스)으로 FWER 0.05 StepM: 활성 집합 최대통계량의
95% 분위 초과 시행을 기각·제거, 반복. **기각 집합 = 생존 집합.** "상위 몇 개"
사후 선택 금지.

### 6.4 Deflated Sharpe Ratio (병기 게이트)
Bailey & López de Prado, SWEEP-2026-08-31 §6.4 와 동일 정의:
`SR0 = √Var[SR_n] × [(1−γ)·Z⁻¹(1−1/N) + γ·Z⁻¹(1−1/(N·e))]`, `N = 1,248`,
`Var[SR_n]` = 1,248 시행 일 단위 Sharpe(`mean/ω̂`)의 표본분산(ddof=1),
`γ3/γ4` = 해당 시행 일수익률 왜도·(비초과)첨도, `T = 2,056`. 전부 비연환산.

### 6.5 통과 기준 (동결)
> **통과 = RC p < 0.05 AND StepM 기각 ≥ 1 AND (StepM 생존 시행 중 DSR ≥ 0.95 존재)**

- RC 와 DSR 은 같은 현상의 두 보정 — AND 게이트는 검정력을 의도적으로 낮춘다
  (위양성 비용 > 위음성 비용, SWEEP 결론 승계).
- 동점은 §3.8 시행 ID 사전순.
- **통과해도**: §0/§2.2 — 즉시 승급 불가. 전방 검증 별도 사전등록 필수.
