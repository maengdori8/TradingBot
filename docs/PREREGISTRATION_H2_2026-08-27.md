## 1. 지위 (중요)

"역사 감사 후 추가된 전향 H2 — 관측된 하방 일관성이 미래 수익을 예측하는가?"

- **H1(월ROI 순위) 동결의 해제가 아님.** 동일 상위가설군("과거 성적으로 카피 대상 선별
  가능한가")의 대안적 선택 규칙. H1 실패는 H1 규칙만 종료하고 H2에 영향 없음(역도 동일).
- **이중 트랙**:
  - (A) 빠른 H2 = 역사 주간곡선 기반, 자본 권한 **영구 없음**, 보조검정.
  - (B) 본검정 H2 = fills+일별 perpAllTime 전향 수집 기반, 통과 시에만 2단계(카피-팔로우
    **페이퍼** 설계) 진입.
- **실거래 권한은 어느 트랙에도 없음.** 자본 관련 권한의 최초 가능일은 트랙 B의
  2027-01-25 이며, 그것도 페이퍼 설계 진입일 뿐이다.

## 2. 트랙 A: 빠른 H2 (역사곡선)

### 2.1 형성 (랭킹) — 입력: logs/trader_portfolio.jsonl.gz (2026-08-26 수집, SHA256 기록)
- 코호트: logs/trader_cohort.json.gz 5,790지갑 그대로 (신규 스크린 금지).
- 위상정렬 주간 그리드: perpAllTime 곡선 타임스탬프의 위상(mod 168h 최빈)으로 그리드 고정.
  각 그리드점 스냅 = 그리드시각 **이전**(후방만) 최근접 곡선점, 후방 3일(72h) 이내만 유효.
- 트레일링 26주 윈도우 (곡선 수집시각 이전 마지막 유효 그리드점에서 역산).
- 주간 수익률 r_w = (pnl(g_{w+1}) − pnl(g_w)) / A_fix.
  A_fix = 윈도우 시작 그리드점의 acct 스냅 (고정분모, ≥ $10,000 필수).
  주 유효 조건: 양끝 스냅 존재 AND 실제 스팬 5–9일.
- 흐름 필터 (1차): 주간 |Δacct − Δpnl| / acct(주 시작) ≤ 20% 인 주만 유효.
- 적격: 흐름-유효 주 ≥ 20/26 AND 형성기간 총 perp PnL > 0
  (pnl(윈도우 끝 스냅) − pnl(윈도우 시작 스냅) > 0).
- **1차 지표 ES20**: k = ceil(0.2 × n_유효주), ES20 = 최저 k개 r_w 산술평균.
  높을수록 우수. 내림차순 랭킹.
- 동결 산출물: logs/h2_cohort.json.gz (주소, ES20, 랭크, 유효주수, A_fix, 진단지표,
  입력파일 SHA256, 생성시각).

### 2.2 검정력 한계 정직 명기 (MDE)
- 설계 시 예상 1차 표본 n≈274 (Codex 개산 — 흐름≤20%·유효주≥20만 적용, MDE IC≈0.17).
- **실현 1차 표본 (스크린 실행 결과, 전방 데이터 조회 전 확정): n=136.**
  개산 대비 축소 원인: 개산에 없던 윈도우 시작 스냅 존재·A_fix≥$10k·형성 총 PnL>0
  조건의 교집합. **실현 MDE: 단측 α=.025, power 80%에서 검출가능 IC ≈ 0.24.**
  (감도 표본: 흐름≤50% 246, 유효주≥16 267.)
- 즉 IC 0.05~0.24 구간의 참효과는 이 표본으로 놓칠 확률이 높다. 상·하위 십분위는 각각
  14·13지갑뿐이다. **기준 미달은 중소 효과 '부재'의 증거가 아니다** — 트랙 A 미달은
  "대형 효과 부재"까지만 말할 수 있다. 이것이 트랙 A가 보조검정에 머무르고 자본 권한이
  영구 없는 이유 중 하나다.

### 2.3 T0 기준선 (사전등록 커밋 **후** 수집 시작)
- 전 코호트 지갑의 portfolio API perpAllTime 직접 수집 (일별 리더보드 alltime_pnl 사용 금지 —
  Codex 실측: 두 계열 중앙 $8.8k / 90분위 $679k 괴리).
- 지갑별 저장: P_perp(T0) = perpAllTime pnl 최종점, A(T0) = acct 최종점, captured_at_utc.
- **T0 초기화는 단일 절차**로 수행한다: ① portfolio t0 스냅샷 → ② clearinghouseState
  포지션 기준선 → ③ 전 지갑 fills 커서 기준선(첫 폴링). 첫 fills 응답이 2,000건
  만석이면 해당 지갑에 `initial-window-truncated` 플래그를 기록한다 (T0 이전 이력
  미관측 — 보유시간은 어차피 left-censored이나, 초기 절단을 명시적으로 표시).
- 스냅샷 파일은 라벨(t0/daily/verdict)로 구분 저장·조회하며, 평가기는 지정 라벨의
  행만 사용한다 (같은 날짜의 daily 재시도가 t0 기준선을 덮는 경로 차단).
- **T0 = 2026-08-27** (수집 시작 시각 기록). 판정일 **T+30 = 2026-09-26**,
  **T+60 = 2026-10-26**, **T+90 = 2026-11-25** (T+90은 세 번째 기회 아님 — 기술통계 확인점).

### 2.4 전방 결과변수 (판정일마다 동일 방식 재수집)
- **확정식**: Y = clip( (P_perp(T_H) − P_perp(T0)) / A(T0), −0.95, +5.0 ).
  unclipped는 감도분석.
- 결측 규칙: ① 판정일 직접 재시도 → ② 판정시각 이전 24h 이내 스냅 →
  ③ 실제 스팬 ≠ H이면 기간 정규화 Y × (H / 실제일수); 스팬 [25, 35]일 밖이면 제외.
  제외 지갑수를 ES20 십분위별 공개.
- **판정불가 규칙**: 결측률 > 10% 또는 결측이 점수와 유의 상관 (Spearman p<0.05)이면
  **판정불가** (기각 아님).

### 2.5 검정 (평가 코드도 지금 동결 — 데이터 조회 전 작성)
- Spearman IC (ES20 랭크 → Y), 동점 average rank.
- **층화 순열**: log(A(T0)) 3분위 × log(1+T0회전율) 3분위 = 9층, 층 내 Y 라벨 순열,
  10,000회, seed=20260827, p = (1 + #{perm IC ≥ 관측 IC}) / 10,001. 무층화는 감도분석.
- 통과 기준(자본 권한과 무관, 보고용): IC ≥ +0.05 AND 단측 p < 0.025 AND
  상위−하위 십분위 Y 스프레드 ≥ +3%p AND 상위 십분위 Y 중앙 > 전체 중앙.
- 2차/감도 (통과 권한 없음): 흐름≤50%, 유효주≥16, unclipped, 무층화,
  고회전율 서브그룹(회전율 상위 3분위 — "단타" 명칭 금지, "고회전율"만), 양수주비율,
  median/IQR — 전부 기술적 보고만.

### 2.6 구현 확정 해석 (동결 전 명문화 — 감사 지적 반영)
명세 자구가 복수 해석을 허용하는 지점의 구현 선택을 결과 조회 전에 고정한다.
- **층화의 "T0 회전율"** = 코호트 잠금(2026-08-25) 시점의 t0_month_vlm / t0_account 로 고정.
  (T0 스냅샷 계약에 거래량 필드가 없어 동결 가능한 유일한 선택.)
- **위상 추정** = "mod 168h 최빈"을 주간샘플 필터(인접간격 168±6h) 후 1h빈 최빈 → ±3h
  원형 중앙값으로 정교화. (촘촘한 최근 구간이 최빈을 오염시키는 것을 막는 보호적 구체화.)
- **그리드 오프셋 +36h** = 그리드 t_k ≡ φ + 36h (mod 168h). 실측(2026-08-27, 주간 샘플
  231,606점): 샘플 위상은 φ 주변 ±1.3h(p01~p99) 지터하므로, 그리드를 φ에 두면 φ 직후에
  떨어지는 ~50% 샘플의 후방 스냅이 한 주 전으로 미끄러져 유효주가 붕괴한다(실측 중앙 6주).
  +12h~+48h 오프셋의 주간샘플 포착률은 99.8%로 유사하지만, **오프셋은 일부 지갑의 윈도
  앵커(gi_last)를 한 주 이동시켜 실제 적격 집합·ES20이 조금씩 달라진다** (Codex 재계산:
  적격 135~139, ES20 상이 지갑 수십 개). +36h는 전방 결과를 일절 보지 않고 후방 72h 창의
  기하학적 중앙으로 고정한 값이다. 후방 스냅만 쓰는 원칙(미래 점 사용 금지)은 불변.
- **형성종료 그리드 이질성 공개**: 적격 136지갑의 형성종료 그리드는 4종 —
  2026-08-21 124개 / 08-14 4개 / 07-31 7개 / 07-24 1개. 12개 지갑의 형성 윈도는 주된
  것보다 1~4주 오래됐다(곡선 말단 결손). 판정 결과 보고 시 이 이질성을 재공개한다.
- **결측 규칙 적용 순서** = 클리핑 후 기간 정규화 (×(H/실제일수)). 정규화된 |Y|가 클립
  경계를 최대 ×1.2 초과할 수 있음을 허용한다 (테스트로 고정된 동작).
- **결측~점수 상관의 유의성 검정** = 순열 양측 p (10,000회, seed=20260827).
- **판정일 운영**: verdict 실행 시 판정시각(--judgment)을 명시한다. 기본값(T_H 파일
  captured_at 최댓값)은 수집 재시도가 이틀에 걸치면 첫날 수집분을 부당 제외할 수 있다.

## 3. 트랙 B: 본검정 H2 (전향 fills + 일별 perpAllTime)

### 3.1 수집 (오늘 시작 — 기존 00:40 러너와 별개의 자매 워크플로 h2-collectors.yml:
일별 UTC 00:50 + 고회전율 intraday 06:50/12:50/18:50)
1. **일별 perpAllTime 수집기**: 전 코호트 portfolio API 일 1회, 지갑별
   (pnl 최종점, acct 최종점, captured_at) 저장. 레이트리밋 준수(§5 운영).
2. **fills 수집기 프로토콜**: 전 코호트 userFills 일 1회.
   - append-only 원본 저장(일별 gzip), fill ID(tid)로 중복 제거.
   - 응답별 oldest/newest fill timestamp 기록.
   - 연속성: 이번 응답이 직전 폴링의 newest ts를 덮어야(겹침) 인정.
   - **cap 실측 정정 (동결 전 확정)**: userFills 응답 cap = **2,000건**, 소급 가용 윈도
     (userFillsByTime) = 최근 **10,000건**. 응답 2,000건 만석 AND 겹침 실패 시
     userFillsByTime(startTime=직전 newest ts)으로 2,000건씩 페이지네이션 소급해 갭을
     채우고, 가용 윈도(10,000건)를 소진해도 커서에 못 미칠 때만 즉시 `fill-history-censored`
     (기술통계만, 랭킹·통과 권한 없음, 원본 저장 생략하고 집계만: 체결수·명목·maker비중·ts범위).
   - T0 이전 오픈 포지션 = left-censored (T0에 clearinghouseState 포지션 스냅 1회 저장).
     형성 종료까지 미청산 = right-censored. 보유시간 통계는 완전관측 에피소드만.
   - 고회전율(회전율 상위 3분위) 지갑은 6시간 간격 적응 폴링 (절단 완화).
3. API 실패 규칙: 일시 실패 후 다음 응답이 이전 cursor를 덮으면 복구. 못 덮으면 해당 지갑
   불완전 처리. 스키마 변경 시 원본 보존 후 수집 중단(사전검증된 결정적 변환 없으면 재시작).
   기술 실패는 H2 기각이 아니라 **판정불가**. 사후 폴링빈도·적격기준 완화 금지.

### 3.2 형성·판정 (랭커 코드 lab/h2_trackb.py — 지금 작성·동결, 형성 데이터 조회 전)
- T0_main = 2026-08-27. 형성 = T0부터 연속 7×24h 비중첩 블록 × 13 = 91일,
  **형성 종료 2026-11-26**. (ISO주 금지 — T0 앵커 블록.)
- **경계 스냅 (지금 고정)**: 경계 t_k = T0 스냅샷 captured_at + k×(7×24h), k=0..13.
  스냅 = t_k **이전**(후방만) 마지막 일별/T0 스냅샷(captured_at 기준), **후방 48h 이내만**
  (일별 수집 + GitHub cron 지연 허용). 미래 스냅 사용 금지.
- 주간 수익률 r_w = (P_perp(t_{k+1}스냅) − P_perp(t_k스냅)) / A(T0_main).
  A(T0_main) = t0 라벨 스냅샷의 account_value, **≥ $10,000 필수** (미달 제외).
- **주 유효 (지금 고정)**: 양끝 스냅 존재 AND 실제 스팬 [6, 8]일 AND 주시작 acct > 0.
- **흐름 필터 (지금 고정)**: flow_frac = |Δacct − Δpnl| / acct(주시작). 1차 ≤ 20%,
  감도 ≤ 50% — 트랙 A와 동일.
- **적격 (지금 고정)**: 흐름-유효 주 ≥ **10/13** (감도 ≥ 8/13) AND 형성 총 perp PnL > 0
  AND `fill-history-censored` 아님 AND 형성 종료 시점에 7일 초과 미해소 gap-incomplete
  아님. (문서 §3.1의 "절단 지갑 랭킹 권한 없음"을 적격식에 명시적으로 반영.
  fills 사유 제외 지갑 수는 별도 공개하고, 그 비율이 코호트 잔존의 30%를 넘으면
  fills 기반 서브그룹 분석은 판정불가.)
- 랭킹 = ES20 (k = ceil(0.2 × 유효주수)). 빠른 H2(26주)와 "동일한 하방 일관성
  구성개념의 다른 lookback" — 동일 estimator 아님을 명기.
- **일별 fills 원본의 최종 중복 제거**: 분석 단계에서 전역 tid 기준 중복 제거를
  수행한다 (크래시 복구·재폴링으로 생긴 원본 중복은 여기서 흡수 — 수집 단계
  중복은 허용, 분석 단계 유일성은 보장).
- **전방 기준선**: 형성 종료일 2026-11-26에 verdict 라벨 portfolio 직접 수집 —
  이것이 트랙 B 전방 Y의 분모·기점 (A(형성종료) 고정분모, T0_main 아님).
- 판정: **T+30 = 2026-12-26**, **T+60 = 2027-01-25**, **T+90 = 2027-02-24**.
  결과변수·검정 = 트랙 A와 동일 형식 (portfolio 직접 재수집, 동일 클리핑·층화 순열·p<.025).
- **게이트 상태 (지금 고정)**: 각 판정 결과를 logs/h2_trackb_gate.json 에 기록
  (판정일·3기준·p·표본·판정불가 여부). **2단계 진입 조건: T+30 AND T+60 모두
  3기준+p 전부 충족** → 최초 가능일 **2027-01-25**. 그것도 카피-팔로우 **페이퍼**
  설계 진입일 뿐 실거래 권한이 아니다. 유효 표본별 MDE를 결과와 함께 의무 보고.
