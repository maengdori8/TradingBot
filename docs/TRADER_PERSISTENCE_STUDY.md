# 트레이더 실력 지속성 연구 — 사전등록 (2026-08-25 코호트 잠금)

## 질문
"진짜 실력 좋은 트레이더의 매매를 분석해 따라하면 수익이 나는가?"
이 질문의 전제 — **과거 성적 상위 = 실력** — 자체를 먼저 검증한다.

## 왜 이 순서인가
- 레버리지 트레이더 수천 명 중 일부는 **순수 운으로** 몇 달 연속 고수익을 낸다.
  과거 성적으로 상위를 고르는 것은 로또 당첨자를 고르는 것과 통계적으로 동일할 수 있다.
- 이 함정은 본 저장소가 두 번 밟을 뻔한 것과 같다 (인샘플 최선 설정 선택 = 사후선택).
- 문헌의 다수 결과: 리더보드 성과의 지속성은 근사 0, 카피트레이딩 팔로워는 평균 손실.
- **거래소 리더보드는 검증 불가** (승자만 노출 + 봇 차단 확인: Bybit/Binance API 접근 거부).
- **Hyperliquid는 전 지갑(43,697개) 손익이 공개** → 패자 포함 전 모집단으로
  생존편향 없는 코호트 구성이 가능. 이것이 유일하게 정직한 검증 경로다.

## 설계 (변경 금지)
- **코호트**: 2026-08-25 잠금, 5,790개 지갑.
  필터는 **활동 기준만**: 계좌 ≥ $10,000 AND 월 거래대금 ≥ $1,000,000.
  성과 필터 금지 — 성과로 고르면 그 자체가 선택편향이다. 패자 포함.
- **T0 순위 변수**: 잠금 시점의 트레일링 월 ROI, [−95%, +500%]로 클리핑
  (입출금 왜곡 ROI 차단 — 실측: 월 ROI +4,464만% 지갑 존재). PnL 순위를 강건성 비교.
- **관측**: 매일 UTC 00:40 코호트 전 지갑의 계좌가치·일/월 손익·거래대금 기록
  (`logs/trader_daily/*.csv.gz`, 지갑당 하루 1행).
- **판정 시점**: T+30 / T+60 / T+90 (2026-09-24 / 10-24 / 11-23). 그 이전 중간 조회는
  운영 점검용이며 판정에 사용하지 않는다.

## 판정 기준 (사전 고정)
| 지표 | 통과 기준 |
|---|---|
| Spearman 순위 IC (T0 월ROI → 전방 30일 ROI) | ≥ +0.05, 순열검정 p < 0.05 |
| 상위 − 하위 십분위 전방 30일 수익 스프레드 | ≥ +3%p |
| 상위 십분위 전방 수익의 중앙값 | > 코호트 중앙값 |
- 세 기준 **모두** T+30과 T+60에서 통과해야 2단계(카피-팔로우 페이퍼 설계) 진행.
- 하나라도 미달이면: **"상위 = 로또" 확정, 카피 가설 폐기.** 재탕 금지.
- 사전 기대(정직): 문헌상 폐기 확률이 높다. 그래도 검증하는 이유는 데이터가 공짜이고
  통과 시 가치가 크기 때문이다.

## 2단계 미리보기 (통과 시에만)
Hyperliquid는 임의 지갑의 **실시간 포지션도 공개**(clearinghouseState)이므로,
시점보존 카피-팔로우(전일 상위 지갑 선정 → 지연 반영 추종)를 페이퍼로 검증할 수 있다.
지연·용량·수수료를 정직하게 반영한다. 통과 전에는 설계하지 않는다.

## 부록: 역사적 파일럿 (2026-08-26 사전등록 — 결과 조회 전 커밋)

30일 대기를 압축하기 위해 portfolio 곡선(지갑별 전 기간 누적 손익)으로 과거 월쌍
지속성을 소급 측정한다. **지위: 판정이 아니라 파일럿.** 생존편향은 양방향으로 작동
가능(콜라이더: 나쁜 달 후 생존 조건이 인위적 평균회귀 생성)하므로, 여기서의 기각도
'생존자 스크린 기각'일 뿐이며 최종 판정 권한은 전향 연구(T+30/60/90)에 있다.

### 방법 (고정)
- 확인 표본: 코호트 순서 301~5790 (앞 300개는 코드 개발 파일럿으로 소진 — 확인에서 제외)
- 곡선: perpAllTime (perp 손익만). 실측 주간 샘플링(경계 브래킷 중앙 168h)
- 월 유효성: 경계 브래킷 ≤168h AND 월 내부 실점 ≥1 (한 선분이 두 경계 통과 금지)
- PIT 적격: 월초 계좌 ≥ $10,000 (미달 제외, 바닥값 대체 금지)
- 흐름 제외: |Δ계좌 − Δ손익| > 월초 계좌 50% 인 달 제외
- 1차 통계: 상위 십분위 전방 중앙 ROI − 동월 적격 전체 중앙 (상위−하위 아님 —
  '패자 지속'만으로 벌어지는 스프레드 배제)
- 추론 단위 = 월. 월 단위 부호 순열검정. 크기 통제 부분 IC 병기.
- 보간 오염 차단 검사: **t→t+2 (한 달 건너뛰기)** — 공유 선분이 없으므로
  이것이 양수면 보간으로 설명 불가

### 통과 기준 (Codex 11라운드 제시안 그대로, 결과 조회 전 고정)
(a) 상위십분위 전방 중앙 양수 월 ≥ 79% · (b) 그 월중앙 ≥ +2%/월 ·
(c) 상위 양수비율 중앙 ≥60% 이고 전체 대비 ≥ +10%p · (d) IC>0, 월 순열 p<0.05
— 전부 충족 시 "파일럿 통과 → 2단계(시점보존 카피-팔로우 페이퍼) 설계 착수".
하나라도 미달 시 카피 가설은 전향 연구 판정까지 동결.

알려진 한계: 주간 해상도로 월 가장자리 ±1주 손익 귀속 오차, 실현/미실현 구분 불가,
입출금 추정은 근사, 오늘 기준 활동 필터가 코호트 정의에 이미 개입.

## 결과: 역사적 검증 (2026-08-26 실행 — 카피 가설 동결)

### 경과
1. **사전등록 파이프라인(달력월·72h 브래킷): 표본 붕괴로 판정 불가.** 원인 실측:
   perpAllTime 곡선은 정확히 주간 샘플링(경계 브래킷 중앙 168h). 168h 완화 후에도
   복합 필터 생존 월쌍 2개(기준 ≥6).
2. **fills 원본 경로 불가**: 엔드포인트가 최근 ~1만 체결만 보관 — 고활동 코호트는
   몇 주치뿐.
3. **v3 탐색(보간 제로, 점-앵커 28일 윈도우)**: 3,450지갑 × 18기간쌍 —
   IC +0.037(p=0.20), 상위십분위 전방 중앙 **−9.96%**, 전체 대비 **−8.58%p**.
4. **Codex 감사판(위상정렬 그리드·후방 스냅만·스팬 24-32일·흐름≤20%·고정분모
   — 분모성장 편향·스냅 룩어헤드 제거)**: 17기간쌍 — **IC −0.005 (p=0.54)**,
   상위십분위 전방 중앙 −7.38%, 전체 대비 −7.21%p. 4개 기준 전부 미달.

### 판정
**카피-팔로우 가설 동결.** 정확한 표현(Codex 12라운드 합의): "뒷받침 증거 부재 +
불리한 탐색적 증거로 동결" — 사전등록 파이프라인은 '판정 불가'였고 v3/감사판은
탐색적이므로 '사전등록 기각 입증'이라고는 주장하지 않는다. 역전(-7%p) 역시
17개 기간·p>0.05로 입증된 것이 아니다 — 역전 베팅도 금지.
재개 권한은 전향 연구(T+30/60/90, 일별 정밀 데이터)에만 있다.

### 교훈
- 파일럿(대형지갑 300개·보간 포함)의 IC +0.21/상위 +21%는 **보간 오염 + 부분표본**의
  산물이었다. 통제를 더할수록 신호가 소멸: +0.21 → +0.04 → **−0.005**.
- 플랫폼 주간 스냅샷은 전 지갑 동일 요일(위상 고정) — 그리드 정렬 필수.
- "과거 수익률로 고른 상위 트레이더"는 이 데이터에서 미래 초과수익의 증거가 없다.
