# ICT Technical Execution Overlay 검증 보고서

## 결론

**FAIL — 실거래 부적합.**

4회 분할진입, 고정 최후 손절, 실제 24시간 보유 제한과 위험예산 통제는 의도대로 동작했다. 그러나 신호의 비용 후 예측 우위는 확인되지 않았다. 기본 68점·비용 5.5bp/side에서 9개 심볼×시간봉 셀 중 전체 구간 양수는 3개, 마지막 25% 홀드아웃 양수는 2개뿐이었다.

- 거래소: Bybit linear perpetual
- 심볼: BTC/USDT:USDT, ETH/USDT:USDT, SOL/USDT:USDT
- 원본: 각 심볼 259,200개, 총 777,600개 1분봉
- 기간: 2026-03-04 00:52 UTC ~ 2026-08-31 00:51 UTC
- 파생 시간봉: UTC 경계의 완전한 5분·15분 OHLCV
- 기본 점수: 68/100, 반대 방향 우위 12점, ICT 최소 3점
- 손절: 1.2~2.5 ATR 구조 제한 + 비용 대비 최소 가격폭 0.25%
- 익절: 평균 진입가 기준 1.8R
- 위험 배분: 최초와 추매1~4 각각 총 위험예산의 20%

- 추매 확인: 순차 가격 터치 + 원래 방향 재확인 캔들 + 내부 합의 유지

- 동일 봉 손절·목표 동시 터치: 손절 우선

## 게이트

PASS 조건은 다음과 같이 사전에 고정했다.

- 기본 9개 셀 모두 양의 기대값
- 홀드아웃 9개 중 최소 7개 양의 기대값
- 합산 PF 1.10 이상
- 부트스트랩 기대값 5% 하단이 0 초과

실제 결과는 `3/9`, `2/9`, PF `0.654`, 부트스트랩 5% 하단 `-0.115R`로 모두 미달했다.

## 해석

- 여러 지표의 합의는 정보 정리에는 유용하지만 독립적인 알파를 자동으로 만들지 못했다.
- 1분·5분에서는 거래비용과 노이즈 영향이 특히 컸다.
- 0.25% 최소 손절폭은 이전 구조보다 PF를 개선했지만 수익성을 만들지는 못했다.
- 추매1은 약 56~60%, 추매2는 17~21%, 추매3은 2.7~5.1%, 추매4는 0~0.7% 거래에서 발생했다. 후반 추매는 드물었고, 4회 추매가 손실 구조를 해결하지 못했다.
- 15분 전체 구간은 세 종목 모두 손익분기 부근 또는 소폭 양수였지만 ETH 15분 홀드아웃은 다시 음수였다. BTC·SOL 15분 홀드아웃 두 셀의 양수만으로 일반화할 수 없다.

따라서 현재 지표는 주문 자동화나 실거래 판단에 사용하면 안 된다. 새로운 논리를 제안하려면 이 데이터의 마지막 홀드아웃을 더 이상 튜닝에 쓰지 말고, 새로운 미래 데이터와 페이퍼 트레이딩으로만 재검증해야 한다.
