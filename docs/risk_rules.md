# 리스크 관리 규칙

## 1. 자본 배분 구조

```
전체 자산: 5,000 USDT
├── 트레이딩 자본 (25%): 1,250 USDT  ← 봇이 사용하는 금액
└── 보호 자본 (75%): 3,750 USDT      ← 절대 건드리지 않음
```

트레이딩 자본만 손실 위험에 노출. 최악의 경우에도 전체 자산의 25%만 손실.

## 2. 포지션 사이징 공식

```
리스크 금액 = 트레이딩 자본 × risk_per_trade
            = 1,250 × 1% = 12.5 USDT

포지션 수량 = 리스크 금액 / |진입가 - 손절가|

예시 (BTC 50,000, SL 49,500):
수량 = 12.5 / 500 = 0.025 BTC
명목 가치 = 0.025 × 50,000 = 1,250 USDT (레버리지 5x 사용 시 실제 담보 250 USDT)
```

최소 R:R = **1:2** (TP = 진입가 ± 손절 거리 × 2)

## 3. 서킷브레이커 조건

| 조건 | 한도 | 조치 |
|------|------|------|
| 일일 손실 | 트레이딩 자본의 3% (37.5 USDT) | 당일 거래 중단 |
| 주간 손실 | 트레이딩 자본의 8% (100 USDT) | 주간 거래 중단 |
| 연속 손실 | 3연패 | 1일 강제 휴식 |

서킷브레이커 상태는 SQLite(`logs/circuit_breaker.db`)에 영속화.
봇 재시작 후에도 차단 상태 유지.

## 4. 동시 포지션 관리

- **최대 동시 포지션: 2개**
- 같은 방향 중복 포지션 불허
- 포지션 추가 전 기존 포지션 수익성 확인

## 5. 실전 전환 기준 (페이퍼 → 실거래)

아래 조건을 **모두** 충족해야 실거래 전환:

| 지표 | 최소 기준 |
|------|---------|
| 페이퍼 트레이딩 기간 | 최소 30일 |
| 총 거래 횟수 | 최소 50건 |
| 승률 | ≥ 45% |
| Profit Factor | ≥ 1.5 |
| MDD | ≤ 15% |
| 샤프지수 | ≥ 0.5 |
| 연속 손실 최대 | ≤ 5회 |

실전 전환 후 첫 2주는 포지션 크기를 50%로 축소 운영.
