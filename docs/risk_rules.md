# 리스크 관리 규칙

> **2026-06 갱신**: 신호연구 기반 전략 개정(RR 2.5, 24h 진입, 차등 리스크)에 맞춰 전면 재정렬.
> 단일 진실원천은 `config/config.yaml` — 이 문서는 설명용이며 수치가 어긋나면 config가 우선.

## 1. 자본 배분 구조

```
전체 자산: 5,000 USDT
├── 트레이딩 자본 (25%): 1,250 USDT  ← 봇이 사용하는 금액
└── 보호 자본 (75%): 3,750 USDT      ← 절대 건드리지 않음
```

트레이딩 자본만 손실 위험에 노출. 최악의 경우에도 전체 자산의 25%만 손실.

## 2. 포지션 사이징 (컨플루언스 점수 차등)

리스크 금액 = 트레이딩 자본 × 점수별 risk_pct:

| 등급 | 점수 | risk_pct | 리스크 금액 |
|------|------|----------|------------|
| A | 85+ | 0.7% | 8.75 USDT |
| B | 75~84 | 0.5% | 6.25 USDT |
| C | 70~74 | 0.3% | 3.75 USDT |
| BTC 역추세 | 무관 | 0.3% 강등 | 3.75 USDT |

```
포지션 수량 = 리스크 금액 / |진입가 - 손절가|
손절 = 2.0 × ATR(14) / 목표 = 손절거리 × 2.5  (최소 R:R = 1:2.5)
레버리지 = 자동(손절거리 기반, 최대 10x, 청산가는 항상 손절가 바깥)
```

> 위 risk_pct/문턱은 **자동학습이 가드레일 안에서 조정**한다
> (risk_pct 0.2~1.0%, min_score 65~85, RR 1.5~3.0 — `logs/learned_params.yaml`).

## 3. 서킷브레이커 조건

| 조건 | 한도 | 조치 |
|------|------|------|
| 일일 손실 | 트레이딩 자본의 5% (62.5 USDT) | 당일 거래 중단 |
| 주간 손실 | 트레이딩 자본의 12% (150 USDT) | 주간 거래 중단 |
| 연속 손실 | 7연패 | 1일 강제 휴식 |

> 7연패 기준: 신체제 설계 승률(~40%)에서 5연패는 확률 7.8%의 일상 변동.
> 7연패(2.8%)가 구설계의 "이상 신호" 희귀도와 동급.

서킷브레이커 상태는 SQLite(`logs/circuit_breaker.db`)에 영속화.
봇 재시작 후에도 차단 상태 유지.

## 4. 동시 포지션 관리

- **최대 동시 포지션: 4개** / 심볼당 1개
- 같은 방향 최대 3개 (한쪽 쏠림 방지)
- 총 담보금 < 트레이딩 자본의 80%

## 5. 실전 전환 기준 (페이퍼 → 실거래)

`config.yaml`의 `promote` 섹션 — 아래 조건을 **모두** 충족해야 전환 (점수 100점 만점 가중 평가):

| 지표 | 최소 기준 | 비고 |
|------|---------|------|
| 총 거래 횟수 | ≥ 30건 | 저승률·고RR 체제는 표본 더 필요 |
| 승률 | ≥ 38% | RR2.5 손익분기 28.6% + 마진 |
| Profit Factor | ≥ 1.5 | |
| MDD | ≤ 10% | 40% 승률의 연패 변동 반영 |
| 샤프지수 | ≥ 1.0 | |
| 총 수익률 | ≥ 0% | 손실 상태 전환 불가 |

실전 전환 후 첫 2주는 포지션 크기를 50%로 축소 운영.

## 6. 롤백 트리거 (전략 개정 안전장치)

- 60일 롤링 순R < 0 또는 풀TP 도달률 < 25% → 출구 기하 구설정(1.5ATR/RR2.0) 복귀
- BTC 역추세 강등 거래 100건 누적 시 EV 재평가 (EV<0 → 하드 차단 격상)
